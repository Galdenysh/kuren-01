# src/core/agent

Учебный **агент по правилу**, не языковая модель: нет tokenizer, transformer и вызовов внешнего API. Агент читает число loss из снимка сети и решает, вызвать ли ещё один шаг `Trainer` или остановиться.

## Один цикл

1. **Цель** — порог `maxLoss` и бюджет `maxSteps` (сколько раз агент сам может вызвать обучение).
2. **Снимок** — `forwardSnapshot`: loss по всему XOR, веса и активации как plain data.
3. **Действие** — `decideRule`: если loss уже не выше порога → стоп «цель»; иначе если бюджет кончился → стоп «лимит»; иначе → один `train`.
4. **Инструмент** — при `train` ровно один `trainStep`; при стопе инструмент не вызывается.

Повтор: `cycle()` — один проход; `run()` — серия до стопа (в UI серию ограничивают, в тестах — крошечным бюджетом).
