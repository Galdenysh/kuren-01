# Kuren-01 — план каркаса

Учебная модель, чтобы руками понять, как устроены нейросеть и ИИ-агент. Это не продукт «вместо GPT».

Стек: **TypeScript + React**. Обучение и слои сети должны быть видны на экране, а не только в логах.

Эта сессия поднимает **только каркас**. Код нейросети, обучения и агента пишут следующие агенты. Один агент не реализует весь проект целиком.

## Задача каркаса

1. Git-репозиторий без remote и без коммита
2. Vite + React + TS
3. OpenSpec под Cursor
4. Проектные skills, rules и `AGENTS.md`
5. Пустые слоты `src/nn`, `src/viz`, `src/agent`
6. Заметка, какой плагин ставить под Grok / Composer
7. Срез `xor-training-lab` описан в OpenSpec, но не реализован

## Что следующие агенты не должны ждать от каркаса

- нет тензора, autograd, слоёв, trainer
- нет XOR-стенда и графиков обучения
- нет transformer / LM
- нет агентного цикла

Каждый агент берёт один срез по OpenSpec. Первый: `/opsx-apply` на `xor-training-lab`.

## Архитектура

```
kuren-01/
  src/nn/          слот: тензор, autograd, слои, trainer — с нуля, без PyTorch
  src/viz/         слот: граф сети, активации, веса, график loss
  src/agent/       слот: будущий агентный цикл
  src/app/         оболочка React, без логики модели
  openspec/        спеки и изменения
  .cursor/skills/  как писать nn и viz в этом проекте
  .cursor/rules/   короткие постоянные правила
```

## Очередь срезов

1. `xor-training-lab` — MLP на XOR + визуал
2. Маленький transformer / character LM
3. Агентный цикл: мысль → инструмент → ответ

## Плагин

Для Grok 4.6 и Composer: **pstack**. Для учёбы рядом: **teaching**. Ставятся вручную из Cursor Marketplace. См. `AGENTS.md`.

## Что каркас не делает

- нет кода ИИ-модели
- нет CUDA / Python / Hugging Face
- нет чата «как у GPT»
- нет деплоя
- нет коммита, пока это отдельно не попросят
- нет Origin/GitHub remote, пока это отдельно не попросят
