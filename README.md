# Kuren-01

Учебная нейросеть на TypeScript + React. Практика, чтобы увидеть, как сеть учится, а не продукт «вместо GPT».

Каркас готов. Модель ещё не написана.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.
