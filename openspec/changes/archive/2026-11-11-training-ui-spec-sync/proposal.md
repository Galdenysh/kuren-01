# Proposal

## Why

После архива `xor-training-agent` живой экран разошёлся с `openspec/specs`: обучение только через агента, панель сворачивается, есть сброс сети и «Авто до цели». Спеки всё ещё требуют ручные «Шаг» / «Серия» в лаборатории. Нужно зафиксировать фактическое поведение, чтобы verify и следующие срезы опирались на правду.

## What Changes

- В `training-agent`: убрать требование ручных шагов лаборатории; описать панель (свёрнута / развёрнута), редактируемую цель, «Авто до цели» (`run()` в UI), порядок блоков на странице.
- В `training-lab`: заменить «Manual stepping» на обновление визуализации от шагов агента; добавить **сброс сети** (seed 42, общий trainer, сброс графика loss и агента).
- Код ядра и новых фич вне UI не планируется: apply в основном сверка и мелкие правки подписей, если найдётся drift.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `training-agent`: экран, кнопки, лог, лимиты серии.
- `training-lab`: кто запускает обучение, сброс, обновление графика.

## Impact

- `openspec/specs/training-agent/spec.md`, `openspec/specs/training-lab/spec.md`
- Документация change; код `src/ui` только при расхождении на apply.
- Вне среза: новый алгоритм агента, transformer, ручной train в лаборатории.
