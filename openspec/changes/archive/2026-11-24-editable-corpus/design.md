# Design

## Context

`readCorpus()` возвращает три фиксированные фразы. `CharModel.create(seed)` всегда читает их. Окна режутся внутри строки длиной больше 4 символов. Экран показывает корпус в `<pre>`, а «Начало» уже является полем. См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- Граница core/ui: ядро принимает строку и считает шаги. React хранит текст, модель и снимок. На диск текст не пишется.
- Фиксированный корпус и тест на 4000 шагов остаются для вызова без текста.

**Non-Goals:**

- Подстройка окна, скрытого слоя и seed под длину текста.

## Decisions

### Необязательный текст в `create`

`CharModel.create(seed, text?)`. Без `text` модель читает `readCorpus()`, как сейчас. С `text` алфавит, окна и веса строятся из него. `loss()` и `trainStep()` при пустом списке окон возвращают конечное неотрицательное число и не вызывают `backward`. `snapshot` при пустом алфавите возвращает пустой хвост и не бросает ошибку. Модель сообщает экрану, есть ли окна, чтобы React не повторял правило длины строки.

Альтернатива — менять константу `CORPUS` из React. Тогда следующий запуск теста увидел бы чужой текст.

### Правка текста сбрасывает только веса

Поле учебного текста — `textarea`, начальное значение `readCorpus()`. Изменение отменяет срезы «Обучить» и снимает занятость кнопок, как «Сброс», затем заменяет модель на `CharModel.create(42, text)`. Поле «Начало» не трогается. Снимок считается для этого начала и нового текста. «Сброс» создаёт seed 42 с текстом из поля. Кнопки «Шаг» и «Обучить» смотрят на признак окон из ядра.

Альтернатива — доучивать старые веса на новом алфавите. Размеры матриц от алфавита, старые веса не подходят.

## Risks / Trade-offs

- [Длинный вставленный текст делает 4000 шагов тяжёлыми] → размер пачки не меняется; это тот же цикл, что у трёх фраз.
- [В начале остаются символы старого алфавита] → ядро пропускает неизвестный символ во входе; поле начала не переписывается само.
- [Очистка поля даёт пустой алфавит] → снимок возвращает пустой хвост и конечную ошибку, шаг не вызывает `backward`.

## Migration Plan

Новый аргумент со значением по умолчанию. Откат — вернуть `<pre>` и убрать аргумент. Сохранённого текста нет.
