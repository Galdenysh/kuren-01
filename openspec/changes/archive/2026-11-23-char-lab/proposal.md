# Proposal

## Why

Символьная модель уже учится в `src/core/lm`, но увидеть продолжение можно только тестом. Нужен отдельный экран, который показывает корпус, ошибку и хвост из снимка, не смешивая его с лабораторией XOR.

## What Changes

- Новый экран `src/ui/char`: учебный текст, поле начала, число ошибки, дописанный хвост, кнопки шага, пачки шагов и сброса к seed
- Оболочка `src/ui/app` переключает «XOR» и «Символы». По умолчанию открыт XOR. Лаборатория остаётся смонтированной, поэтому веса, график, лог агента и выбранный вход переживают переключение
- Экран читает только `readCorpus` и `CharModel.snapshot`. Шаг обучения вызывает уже существующий `trainStep`
- `src/ui/AGENTS.md` называет `src/ui/char` рядом с `src/ui/lab`

Вне скоупа: новая математика в `src/core`, веса и граф 68→64→17, трансформер, агент для символьной модели, правка среза XOR.

## Capabilities

### New Capabilities

- `char-lab`: экран, где видно заучивание короткого текста и продолжение строки

### Modified Capabilities

- `project-layout`: граф, таблица весов и график loss XOR остаются в `src/ui/lab`; число ошибки символьного снимка живёт в `src/ui/char`

## Impact

- новые файлы `src/ui/char/**`, переключатель в `src/ui/app`
- импорт публичного API `src/core/lm`; `src/core` не импортирует React
- без новых зависимостей
- браузерная проверка после того, как пользователь сам запустит Dev
