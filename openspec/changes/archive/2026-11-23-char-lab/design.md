# Design

## Context

`CharModel` в `src/core/lm` уже отдаёт `readCorpus`, `trainStep` и `snapshot(prefix, count)`. Лаборатория XOR в `src/ui/lab` рисует другой снимок: `{ loss, weights, activations }`. Оболочка `src/ui/app` показывает только её. См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- Экран `src/ui/char` показывает корпус, поле начала, `loss` и `continuation` из снимка.
- Граница core/ui: ядро считает шаг и снимок. React только хранит экземпляр модели, начало строки и последний снимок. Новой математики в `src/core` нет.
- Экран XOR остаётся экраном по умолчанию.

**Non-Goals:**

- Граф 68→64→17 и таблица весов.
- Компонентные тесты: в проекте нет Testing Library.

## Decisions

### Отдельная папка `src/ui/char`

Компонент экрана, CSS module и `index.ts` лежат в `src/ui/char`. `App` держит режим `xor | char`. `TrainingLab` и `AgentPanel` остаются смонтированными и скрываются вместе с заголовком XOR, чтобы лог агента и выбранный вход не сбрасывались. `src/ui/lab` символьную модель не импортирует.

Альтернатива — вставить блок в `TrainingLab`. Тогда один экран смешивает два снимка.

### Снимок на каждое изменение начала

Модель создаётся как `CharModel.create(42)`. Поле начала по умолчанию — первая фраза корпуса без последних 6 символов, хвост тоже длины 6. Пока первая фраза не короче остальных, это тот же отрезок, что у самой длинной фразы в `lm.test.ts`. Любая правка поля вызывает `snapshot(prefix, 6)`. На экране показывается `snapshot.loss`: до первого шага это средняя ошибка по окнам, после `trainStep` — ошибка последнего окна, не средняя `loss()`.

### Пачка не блокирует страницу на все 4000 шагов

Кнопка «Шаг» вызывает один `trainStep`. Кнопка «Обучить» выполняет 4000 шагов срезами по 50. Между срезами управление отдаётся через `setTimeout` или `requestAnimationFrame`, не через микрозадачу, и на экран кладётся новый снимок. На это время кнопки обучения недоступны. Уход с экрана отменяет оставшиеся срезы. Сброс создаёт модель с seed 42 и новый снимок для текущего поля, само поле не очищает.

Альтернатива — 4000 шагов одним синхронным циклом. Страница замирает до конца.

## Risks / Trade-offs

- [4000 шагов на слабой машине всё равно длятся секунды] → между срезами видна текущая ошибка, кнопка на это время недоступна.
- [Пользователь стирает знакомое начало] → хвост остаётся снимком ядра; совпадение с фразой проверяется на начале по умолчанию.

## Migration Plan

Новый экран и переключатель. Откат — удалить `src/ui/char` и ветку режима в `App`. Ядро не мигрирует.
