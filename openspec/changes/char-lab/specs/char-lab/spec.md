# Spec Delta

## Purpose

Экран показывает, как символьная модель заучивает короткий текст и дописывает строку из снимка ядра.

## ADDED Requirements

### Requirement: Character screen is separate from XOR

Оболочка MUST давать переключение между экраном XOR и экраном символьной модели. При открытии приложения MUST быть виден экран XOR. Экран символьной модели MUST NOT показывать граф, веса и агента XOR.

#### Scenario: Switch screens

- **WHEN** пользователь открывает приложение и переключается на символьную модель, затем обратно
- **THEN** сначала виден экран XOR, затем корпус и продолжение без графа и заголовка XOR, затем снова те же веса, график, лог агента и выбранный вход

### Requirement: Screen shows corpus and snapshot

Экран символьной модели MUST показать учебный текст из ядра, поле начала строки, число ошибки и дописанный хвост. Число ошибки и хвост MUST браться из снимка ядра для текущего начала.

#### Scenario: Continuation follows the prefix field

- **WHEN** пользователь меняет начало строки
- **THEN** на экране виден хвост из нового снимка для этого начала, а учебный текст остаётся тем же

### Requirement: Training controls

Экран MUST дать один шаг, пачку из 4000 шагов срезами по 50 и сброс к seed 42. На экране MUST быть `snapshot.loss`: до первого шага это средняя ошибка по окнам, после шага — ошибка последнего окна. На время пачки кнопки обучения MUST быть недоступны, а число MUST обновляться между срезами. Сброс MUST вернуть стартовую ошибку и MUST NOT очищать поле начала.

#### Scenario: One step updates loss

- **WHEN** пользователь нажимает шаг обучения
- **THEN** на экране ошибка последнего окна из нового снимка

#### Scenario: Train batch updates between slices

- **WHEN** пользователь нажимает обучение пачкой
- **THEN** проходит 4000 шагов, между срезами по 50 видно текущее число снимка, и до конца пачки кнопки обучения недоступны

#### Scenario: Reset restores the start

- **WHEN** пользователь изменил начало, обучил сеть и нажимает сброс
- **THEN** число ошибки как у новой сети с seed 42, хвост пересчитан для того же начала, поле начала не очищено

### Requirement: Seen prefix after training

После достаточного числа шагов продолжение знакомого начала MUST совпасть с хвостом этой фразы из учебного текста.

#### Scenario: Default prefix after one training run

- **WHEN** пользователь открывает экран и один раз нажимает обучение пачкой, не меняя поле
- **THEN** начало — первая фраза корпуса без последних 6 символов, а хвост длины 6 совпадает с окончанием этой фразы

### Requirement: Russian character screen

Пользовательский текст экрана символьной модели MUST быть на русском. Имена в коде MUST оставаться на английском.

#### Scenario: Visible copy

- **WHEN** пользователь открывает экран символьной модели
- **THEN** заголовки, кнопки и подписи на русском
