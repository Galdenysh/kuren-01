# Design

## Context

См. proposal.md — Why. Сейчас Vite + React-оболочка и пустые слоты `src/nn`, `src/viz`, `src/agent`. Каркас не содержит тензора и обучения.

## Goals / Non-Goals

**Goals:**

- Один срез, который другой агент может закрыть за сессию
- Математика в TS читается человеком
- UI только отображает снимок trainer

**Non-Goals:**

- transformer, tokenizer, language model
- агентный цикл и tools
- GPU, Python, сохранение чекпоинтов на диск
- «красивый продукт» вместо учебной ясности

## Decisions

1. **Свой мини-autograd, не библиотека.**  
   Иначе нечему учить. Альтернатива `synaptic.js` / `brain.js` отвергнута: это чёрный ящик.

2. **Снимок состояния (`NetworkSnapshot`) как контракт nn → viz.**  
   Viz не лезет в внутренности тензора. Альтернатива: viz читает приватные поля — хрупко.

3. **Один hidden layer 2 нейрона.**  
   XOR требует нелинейности, но граф остаётся обозримым. Альтернатива: больше слоёв — хуже видно.

4. **Обучение в главном потоке, шаг за шагом.**  
   Для XOR Worker не нужен. Альтернатива: Web Worker — позже, если UI начнёт тормозиться.

## Risks / Trade-offs

- [Случайная инициализация не выучит XOR] → фиксированный seed и достаточное число шагов в задачах
- [Слишком умный агент притащит ML-либу] → skills `kuren-nn` и правило alwaysApply это запрещают
- [Агент начнёт transformer в той же сессии] → tasks.md и `kuren-handoff` режут скоуп
