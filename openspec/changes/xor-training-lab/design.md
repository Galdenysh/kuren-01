# Design

## Context

См. proposal.md — Why. Каркас: `src/core` без React, `src/ui` только отображение. Тензора и обучения ещё нет.

## Goals / Non-Goals

**Goals:**

- Один срез, который другой агент закрывает за сессию
- Сначала падающие тесты ядра, потом код, потом UI
- Математика в TS читается человеком
- UI только отображает снимок trainer

**Non-Goals:**

- transformer, tokenizer, language model
- агентный цикл и tools
- GPU, Python, сохранение чекпоинтов
- полный FSD
- «красивый продукт» вместо учебной ясности

## Decisions

1. **Свой мини-autograd, не библиотека.**  
   Иначе нечему учить. Альтернатива `synaptic.js` / `brain.js` отвергнута.

2. **Снимок (`NetworkSnapshot`) как контракт core → ui.**  
   `src/ui/lab` не лезет во внутренности тензора.

3. **Один hidden layer 2 нейрона.**  
   XOR требует нелинейности, граф остаётся обозримым.

4. **Обучение в главном потоке, шаг за шагом.**  
   Worker не нужен для XOR.

5. **Vitest в `src/core/nn/*.test.ts`, environment node.**  
   UI-тесты с jsdom не входят в этот срез; лабораторию проверяют build + браузер.

## Risks / Trade-offs

- [Случайная инициализация не выучит XOR] → фиксированный seed и достаточное число шагов в тестах
- [Агент начнёт с UI] → tasks идут red-тестами ядра первыми
- [Агент начнёт transformer] → `AGENTS.md` режет скоуп
