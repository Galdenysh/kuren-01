# char-lm Specification

## Purpose

Символьная модель учится продолжать короткий фиксированный текст и показывает заучивание, а не ответ на вопрос.

## Requirements

### Requirement: Fixed character corpus

Вызов без текста MUST обучать модель на одном фиксированном тексте из нескольких коротких фраз. Каждое чтение этого текста MUST возвращать одну и ту же строку. Переданный текст это чтение MUST NOT менять.

#### Scenario: Corpus is stable

- **WHEN** два независимых запуска читают учебный текст
- **THEN** оба получают одну и ту же строку из нескольких фраз

### Requirement: Next-character step

Один шаг обучения MUST брать окно предыдущих символов, сравнивать предсказанный следующий символ с символом из текста и обновлять обучаемые параметры так, чтобы ошибка этого шага могла уменьшиться. Если список окон пуст, шаг MUST NOT брать окно и MUST NOT менять веса.

#### Scenario: Loss is a number after a step

- **WHEN** выполнен один шаг обучения на окне из учебного текста
- **THEN** шаг возвращает неотрицательное число ошибки

#### Scenario: Parameters can move

- **WHEN** выполнено много шагов на одном и том же тексте с ненулевой начальной ошибкой
- **THEN** ошибка на учебном окне становится меньше, чем до этих шагов

#### Scenario: Softmax head

- **WHEN** модель делает шаг по окну символов
- **THEN** скрытый слой проходит sigmoid, ошибка шага — кросс-энтропия следующего символа после softmax, а продолжение берёт символ с наибольшей вероятностью

### Requirement: Caller-supplied training text

Модель MUST уметь учиться на тексте, который передал вызывающий код. Вызов без текста MUST по-прежнему брать фиксированный корпус. Пустой список окон после обрезки пробелов MUST NOT бросать ошибку на шаге, на чтении ошибки и на снимке. При пустом алфавите хвост снимка MUST быть пустым.

#### Scenario: Custom text is memorized

- **WHEN** модель создают с фразой, которой нет в фиксированном корпусе, и обучают столько же шагов, сколько нужно фиксированному корпусу
- **THEN** хвост совпадает с окончанием переданной фразы, а чтение фиксированного корпуса возвращает прежнюю строку

#### Scenario: No windows

- **WHEN** модели передают текст с пустым списком окон, включая пустую строку и строку из одних пробелов, и вызывают шаг
- **THEN** шаг завершается, ошибка до шага конечная и неотрицательная, веса те же, снимок не бросает ошибку, а при пустом алфавите хвост пустой

### Requirement: Continuation of a seen prefix

После обучения продолжение знакомого начала MUST состоять только из символов учебного алфавита и MUST совпадать с учебным текстом на заметном отрезке, а не быть ответом своими словами.

#### Scenario: Memorized phrase continues

- **WHEN** модель обучена и получает начало фразы, которая есть в учебном тексте
- **THEN** дописанный хвост повторяет продолжение этой фразы из учебного текста

### Requirement: Unfamiliar prefix is not an answer

Продолжение начала, которого нет в учебном тексте, MUST оставаться цепочкой символов учебного алфавита. Модель MUST NOT требовать отдельного режима «ответить на вопрос».

#### Scenario: Question-shaped prefix

- **WHEN** модель обучена и получает начало, которого нет среди учебных фраз
- **THEN** она дописывает символы из учебного алфавита тем же способом, что и для знакомого начала

### Requirement: Plain snapshot

Снимок для вызывающего кода MUST быть обычными данными: текущая ошибка и текст продолжения. Снимок MUST NOT отдавать внутренние массивы параметров.

#### Scenario: Caller reads continuation

- **WHEN** вызывающий код просит снимок после продолжения строки
- **THEN** он получает число ошибки и строку продолжения без доступа к параметрам сети
