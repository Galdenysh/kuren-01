# training-agent Specification

## Purpose

Учебный агент ведёт уже существующий цикл обучения XOR: смотрит снимок, решает правилом и вызывает шаг trainer, пока цель или бюджет не остановят цикл.

## Requirements

### Requirement: Rule chooses train or stop

Агент MUST выбирать действие только по цели и последнему снимку. Пока loss выше порога и бюджет шагов не исчерпан, действие MUST быть одним шагом обучения. Если loss не выше порога, агент MUST остановиться, потому что цель достигнута. Если бюджет шагов исчерпан, агент MUST остановиться из‑за лимита. Выбор MUST делать фиксированное правило, не языковая модель.

#### Scenario: Loss still high

- **WHEN** снятый loss выше порога и выданных шагов обучения меньше бюджета
- **THEN** следующее действие — ровно один шаг обучения

#### Scenario: Goal reached

- **WHEN** снятый loss не выше порога
- **THEN** агент останавливается и не выдаёт ещё один шаг обучения

#### Scenario: Step budget exhausted

- **WHEN** число выданных шагов обучения достигло бюджета, а loss всё ещё выше порога
- **THEN** агент останавливается и не выдаёт ещё один шаг обучения

### Requirement: Cycle observes before it acts

Каждый цикл MUST идти в порядке: цель, снимок, действие, затем инструмент. Снимок MUST быть прочитан до шага обучения. Действие «стоп» MUST NOT вызывать инструмент шага. Действие «обучить» MUST вызвать инструмент шага ровно один раз.

#### Scenario: One learning cycle

- **WHEN** агент выполняет один цикл, и loss выше порога при ненулевом остатке бюджета
- **THEN** сначала появляется снимок, и только потом выполняется один шаг обучения

#### Scenario: Stop skips the train tool

- **WHEN** агент выполняет один цикл, и правило выбирает стоп
- **THEN** инструмент шага обучения не вызывается

### Requirement: Tools stay on the public trainer API

Инструмент снимка и инструмент шага MUST получать данные через публичный API `src/core/nn`. Они MUST NOT читать приватные поля тензора и MUST NOT импортировать React или `src/ui`.

#### Scenario: Observation is a snapshot

- **WHEN** инструмент снимает состояние или делает шаг
- **THEN** наружу выходят loss, веса и активации публичного снимка, а не внутренние поля тензора

### Requirement: Run repeats until stop

Прогон MUST повторять цикл, пока действие не станет стопом. Результат MUST содержать упорядоченный лог: снятый loss, действие и, для стопа, причину (цель или лимит). Лог MUST быть обычными данными, без объектов тензора.

#### Scenario: Budget of two while loss stays high

- **WHEN** порог ниже loss на всём протяжении бюджета в два шага
- **THEN** лог содержит два действия обучения и следом стоп из‑за лимита, а trainer получил ровно два шага

#### Scenario: Already at the goal

- **WHEN** порог не ниже loss до какого‑либо шага агента
- **THEN** первый цикл — стоп из‑за цели, и веса сети не меняются

### Requirement: Screen shows the log and the same lab

Экран MUST показать лог циклов на русском и MUST вести агента и лабораторию одним trainer. Панель агента MUST быть сразу под заголовком страницы, выше блока визуализации. Шаг агента MUST обновить граф, веса и график loss лаборатории. Обучение MUST запускаться только из панели агента; отдельных кнопок ручного шага в лаборатории MUST NOT быть. Одна команда экрана MUST выполнить один цикл; серия MUST быть не длиннее фиксированного предела и MUST закончиться раньше, если правило уже сказало стоп. Стили панели MUST быть CSS modules, без Tailwind и CSS-in-JS.

#### Scenario: Agent step refreshes the lab

- **WHEN** пользователь запускает один цикл, и правило выбирает обучение
- **THEN** в логе виден этот цикл на русском, а лаборатория показывает снимок после этого шага

#### Scenario: Series is capped

- **WHEN** пользователь запускает серию, а цель за предел серии не достигается
- **THEN** выполняется не больше объявленного числа циклов, и страница не уходит в неограниченный цикл

#### Scenario: No manual train in lab

- **WHEN** пользователь открывает лабораторию
- **THEN** нет кнопок ручного одного шага и серии шагов trainer вне панели агента

### Requirement: Agent panel collapses

Панель агента MUST иметь свёрнутый режим: заголовок и кнопки управления без лога и без полей цели. Развёрнутый режим MUST показывать лог циклов и редактируемые порог loss и бюджет шагов.

#### Scenario: Collapsed default controls

- **WHEN** панель свёрнута
- **THEN** видны только заголовок, переключатель разворота и кнопки «Шаг агента», «Серия циклов (50)», «Авто до цели»

#### Scenario: Expanded settings and log

- **WHEN** пользователь разворачивает панель
- **THEN** видны поля цели и прокручиваемый лог на русском

### Requirement: Auto run until stop on screen

Экран MUST дать запуск `run()` агента одной кнопкой до стопа по правилу или бюджету, без бесконечного цикла вне ядра.

#### Scenario: Auto button stops on rule

- **WHEN** пользователь нажимает «Авто до цели» и правило останавливает цикл раньше исчерпания бюджета
- **THEN** в лог попадают все циклы до стопа и страница не зависает
